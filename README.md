# Курсова робота «Бази даних» — варіант 113

**Тема:** проєктування та реалізація бази даних платформи дистанційного навчання
(курси, учасники, навчальні матеріали, завдання та результати виконання).

## Структура репозиторію

```
bd/             сама база даних: SQL-скрипти, REST API (FastAPI + Swagger),
                протоколи запусків, розгортання — див. bd/README.md
docs/           ER-діаграма та знімки Swagger UI (+ скрипти, що їх створюють)
report/         скрипти генерації пояснювальної записки (DOCX/PDF)
presentation/   презентація для захисту (HTML) і скрипт її збирання
```

Швидкий старт бази даних і API — у [bd/README.md](bd/README.md).
